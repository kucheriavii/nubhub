> Інтерактивна веб-платформа, яка допомагає новачкам в IT (Junior / Trainee) оцінити свій стек знань, знайти відповідні вакансії на провідних українських платформах (**Djinni**, **DOU**, **Work.ua**, **Robota.ua**), закрити прогалини в навчанні та порівняти попит на технології.

---

## 🎯 Основні можливості

### 1. 💼 Розумний аналіз вакансій (Skill Gap Analysis)
- Клікаєш на вакансію — сайт миттєво порівнює її вимоги з твоїм профілем.
- 🟢 **Вже знаєш:** підсвічує навички, які в тебе є.
- 🔴 **Потрібно довчити:** показує відсутні скіли, а прямо під ними — **посилання на перевірені книги, безкоштовні курси та інтерактивні тренажери**.
- Розрахунок показника готовності кандидата (**Match %**).

### 2. 🔍 Скіл ➔ Куди підходить
- Обираєш будь-яку технологію (наприклад, `SQL`, `Python`, `React`) та бачиш:
  - Реальний відсоток попиту у вакансіях загалом та окремо по платформах.
  - Список усіх актуальних позицій, де ця навичка є обов'язковою або додатковим плюсом.

### 3. ⚖️ Мульти-порівнялка технологій (Skill Battle)
- Порівняння популярності будь-якої кількості скілів в межах однієї категорії (наприклад, `SQL` vs `PostgreSQL` vs `MySQL` vs `MongoDB` у базах даних або `React` vs `Vue` у фронтенді).
- Візуальні графіки попиту по Djinni, DOU, Work.ua та Robota.ua.
- Аналітична порада, що саме і в якому порядку краще вчити джуну.

### 4. 👤 Профілі користувачів та Рівні володіння
- Авторизація через **Google**, **GitHub** або **Email**.
- Збереження власного набору вивчених скілів у базі даних.
- Градація навичок за рівнями (`Базовий` • `Просунутий` • `Бог`), які в майбутньому підтверджуватимуться тестами (квізами).

### 5. 👑 Адмін-панель та Редактор скілів
- Тільки адміністратор має права додавати нові скіли, коригувати категорії та посилання на курси/книги.
- Автоматичний перерахунок попиту без ручного введення відсотків.

---

## 🛠 Технологічний стек

- **Frontend:** React 18, Vite, Tailwind CSS, Lucide Icons.
- **Backend / Data:** Node.js (Vite API Middleware), вбудована JSON/SQLite база даних з автентифікацією (JWT + SHA-256).
- **Парсинг вакансій:** Вбудований скрейпер реальних вакансій з Djinni та DOU.

## 🚀 Швидкий запуск локально

1. **Клонувати репозиторій:**
   ```bash
   git clone https://github.com/kucheriavii/nubhub.git
   cd nubhub
   ```

2. **Встановити залежності:**
   ```bash
   npm install
   ```

3. **Запустити сервер розробки:**
   ```bash
   npm run dev
   ```

4. Відкрити у браузері: [http://localhost:5173/](http://localhost:5173/)

---

## 🐳 Запуск у Docker (локально або на VPS)

Проєкт повністю докеризовано. Для запуску однією командою:

```bash
docker compose up -d --build
```

Додаток буде доступний за адресою: [http://localhost:3000/](http://localhost:3000/)  
База даних зберігається у persistent volume `nubhub-data` (шлях у контейнері: `/app/data/db.json`), тому ваші користувачі, налаштування та вакансії не зникатимуть після оновлення образу.

Зупинити контейнер:
```bash
docker compose down
```
